# Changelog

## 1.0.0 — 2026-10-19

First public-ready release.

- Journal desk skin for DeepSeek Harness with Nature, Science, IEEE and Elsevier covers.
- Six manuscript stages, from With Editor to Published, each with its own editorial letter.
- Editorial letter rendered as a real conversation background, with adjustable opacity, automatic or custom colour, and a paper-grain switch.
- Sidebar masthead, hero mark and a single lower-left journal/stage switcher in `shell.overlay`.
- Light and dark palettes that follow the Harness theme.
- Local-only settings in `localStorage`; no runtime dependencies and no external network requests.
- Self-contained bundle: Host asset route, Web client module, en/zh plugin-manager metadata and original icon.
