## Icons and fonts

`icon.svg` is an original drawing created for this project.

The skin uses the following system font families when available, without
bundling font files:

- Iowan Old Style / Palatino / Georgia for the journal serif
- SF Mono / Menlo / Consolas for the colophon and manuscript metadata
- The Harness UI font stack for controls and body copy

No font files are redistributed with this package.
